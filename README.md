# kv260-imx219-camera

## Environment

- AMD Kria KV260 Vision AI Starter Kit
- Vivado 2025.2
- Vitis 2025.2
- PYNQ 3.0.1
- Raspberry Pi Camera V2 (IMX219)

## Repository structure

```text
    hls/       Vitis HLS source and configuration
    vivado/    Vivado project
    pynq/      PYNQ capture script and notebook
```

## Assumptions

This project was tested with the following configuration:

- Resolution: 3280 x 2464
- Pixel format: RAW10
- MIPI CSI-2 lanes: 2
- VDMA frame stores: 4
- Output format after HLS conversion: 8-bit grayscale
- Bytes per pixel: 1

## Build and Run

<details open>
<summary> In the case of a GUI </summary>

### 1. Clone

```bash
    git clone git@github.com:Thaiin/kv260-imx219-camera.git
```

### 2. Build HLS IP

1. Launch Vitis
2. Select `hls/Raw10_to_Y8_pack` as the workspace
3. Run `C SYNTHESIS` -> `Run`
4. Run `PACKAGE` -> `Run`

After `PACKAGE` completes successfully, the HLS IP build is complete.

### 3. Build Vivado Project

1. Launch Vivado

2. Open `vivado/vivado.xpr`

3. Open `Project Manager` -> `Settings`

4. Open `IP` -> `Repository`

5. Add the following HLS IP repository

```text
    hls/Raw10_to_Y8_pack
```

6. Run `Report IP Status` again to update `raw10_to_y8_pack`

7. In `Design Sources`, right-click `design_1` and select `Create HDL Wrapper`

8. Select `Let Vivado manage wrapper and auto-update`

9. Make sure `Generated wrapper will be used as Top Module` is enabled, then click `OK`

10. Click `PROGRAM AND DEBUG` -> `Generate Bitstream`

After `Generate Bitstream` completes successfully, the Vivado build is complete.

### 4. Run on PYNQ

1. Prepare the following files generated by Vivado

```text
    vivado/vivado.runs/impl_1/design_1_wrapper.bit
    vivado/vivado.gen/sources_1/bd/design_1/hw_handoff/design_1.hwh
```

2. Rename `design_1_wrapper.bit` to `design_1.bit`

3. Connect the host PC and KV260 to the same network

4. Open the following URL from a web browser on the host PC

```text
    http://<KV260_IP_ADDRESS>:9090
```

5. Open the `kv260` directory in Jupyter Notebook

6. Create a new directory with any name under the `kv260` directory

7. Upload the following files to the created directory

```text
    design_1.bit
    design_1.hwh
    imx219_capture.py
    imx219_capture_test.ipynb
```

`imx219_capture.py` and `imx219_capture_test.ipynb` are located in the `pynq` directory of this repository.

8. Open `imx219_capture_test.ipynb`

9. Run the notebook cells in order
